# The Seven-Layer Reference Harness — channel-law classification of every load-bearing step

**Status:** Built at Trust Layer S8 (2026-07-10) under `D-TRUST-LAYER-S8-REFERENCE-HARNESS-BUILT-DARK-REVIEW-FOLDED`. Governing design: ADR-013 §6 (`adopted/adr/2026-07-08-sage-trust-layer.md` — trust core + reference harness; the seven-layer framing) + ADR-011 (the channel law). This file is the S8 gate deliverable: **every load-bearing step is channel-law-classified before it is trusted.**

**The channel law (ADR-011, live-measured):** OUT-OF-BAND actions (the hook does it, on its own credential; the agent is never asked) bind and survive a resistant agent. INJECTED text is advisory by design — a capable agent may discount it, and a more capable agent discounts harder. **ENFORCE** = binds via the out-of-band channel. **INSTRUMENT** = records/transmits out-of-band; the agent is never asked. **ADVISE** = injected observation; discountable by design. **MEASURE mode throughout: nothing S8 added binds — ENFORCE beyond the already-proven irreversible-action guard-deny is S11** (its own founder-walked Critical activation).

## The load-bearing invariants (asserted by the release gates)

1. **Never self-report (A7 — structural WITHIN the harness; disclosed posture at the route boundary):** inside the reference harness, the L4 audit's input is the transcript tail the harness read (Observability layer) — the orchestrator is never asked, and there is no hook path by which it supplies signals or a clean bill of health; an unreadable transcript ⇒ an empty trace ⇒ the server holds honestly (`audit-unavailable`, never a fabricated pass). **At the `/api/practice/discernment` boundary the trace text is caller-supplied under the authed credential** — the route cannot verify transcript provenance, so CREDENTIAL ISOLATION is the trust boundary there: an install that lets the audited agent read the loop credential could pre-empt its own audit with a curated trace (the write-once column keeps the first record). Mitigations: the write-once refusal is surfaced to the harness (`l4_commit_note` in the spawn record + observability JSONL + the honest log — a pre-existing L4 record is tamper-EVIDENT), and the S9 install walk covers credential isolation. A hook-authenticated trace channel is the structural closure — a named follow-up, not claimed.
2. **R18f-parallel (no record without a verifiable artifact):** trust events derive only from RE-VERIFIED Ed25519 assessments; the L4 `traceRef` names a signed extraction artifact stored durably in the observability JSONL; unverified/blank ⇒ zero events.
3. **MEASURE:** every S8 output carries `mode:"measure"`; the only deny in the harness remains the pre-existing irreversible-action guard. Binding anything else is S11.
4. **Fail-open-honest (KG1/R18):** a discernment/trust-read/hand-back outage never blocks a spawn, a tool, or a stop — it logs honestly (`DISCERN-OUTAGE`, `TRUST-READ-OUTAGE`, `HANDBACK-OUTAGE`) and records nothing false.
5. **Un-provisioned byte-identity:** without `discernment.config.json` (+ credential), every S8 code path returns fast and the H1–H4 harness behaves byte-identically to its pre-S8 form (battery-asserted: negative-battery leg 8, logic-harness case 16).
6. **Dark server:** the `/api/practice/discernment` route answers an honest 503 until `SUBSTRATE_TRUST_CORE_ENABLED` is set — zero LLM spend, zero DB writes while dark.
7. **Schema-field redaction is a RULE, not an authorship (S9, 2026-09-06 — mentor Part 4):** before any text reaches a Layer-1-extracting surface, the harness mechanically replaces the substrate's own internal field identifiers (the defence's `schema_field_injection` list) with `⟨schema-field⟩` and logs `redacted=N`. Without it the A11b defence fails the harness closed on exactly the sessions that maintain the substrate — the Verification layer goes blind where the actions are most consequential. **This does not breach the channel law:** the mentor's ruling is that mechanical redaction with neutral placeholders is *"deterministic, not agent-authored, and does not give the agent any influence over what is sent … shaped by a rule, not by the agent"*, conditional on the rule being disclosed (README §Schema-field redaction) and the redaction being logged (`redacted=N`). **Scope is the examined text only** — the accreditation write and the hand-back carry server-signed envelopes and are deliberately NOT redacted, since altering them would corrupt the signatures that make invariant 2 possible. The defence itself is byte-untouched; a credential-scoped downgrade of it was ruled against. Drift between the harness's list and the defence's is gated by `test/schema-redaction.test.mjs` DIV-1.
