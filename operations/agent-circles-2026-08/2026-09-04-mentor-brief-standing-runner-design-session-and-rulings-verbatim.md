> ### RESEARCH INPUT 1: The Grok bidirectional algorithm
>
> #### Forward algorithm (untangle → generalise)
>
> A tangled correlation structure can be simplified by local, reversible operations that preserve underlying structure. The process:
>
> 1. Represent findings and correlations as a graph. Nodes are atomic findings or concepts. Edges are correlations annotated with strength, direction, and type.
> 2. Insert temporary supports (intermediate abstractions, conditioning variables) into selected subgraphs — holding those relations open while the rest is examined. This is the finger-insertion operation.
> 3. Apply loosening moves (relax a correlation, residualise, cancel opposing links) and tightening moves (strengthen a core relation once surrounding noise is reduced).
> 4. Cancel redundant correlations using Reidemeister-style operations: remove trivial loops (Type I), cancel opposing pairs (Type II), re-route dependencies (Type III).
> 5. Terminate when the residual structure is minimal — no essential crossings remain. That residual is the candidate generalisation.
>
> The four Stoic virtues govern which moves are accepted: practical wisdom checks whether a relation is genuine; temperance prevents overfitting; justice ensures all relevant findings are treated fairly; courage discards a cherished but spurious link.
>
> #### Reverse algorithm (generalise → extrapolate)
>
> The same operations run in the expanding direction:
>
> 1. Anchor the clean residual structure as the fixed core. This must remain intact.
> 2. Insert generative fingers at selected points — intermediate abstractions, boundary conditions, free parameters — as insertion points where new loops can be grown without violating the original topology.
> 3. Apply expanding moves: grow a new loop (inverse Reidemeister I), introduce a controlled pair of crossings (inverse Reidemeister II), slide a new strand past an existing crossing (Reidemeister III expanding).
> 4. Each move is scored by the four Stoic virtues so expansion stays coherent, moderate, and truthful.
> 5. Ground newly grown strands in concrete domains, data, or functions. Any instance continuously deformable back to the core is a legitimate extrapolation.
> 6. Optionally run a short forward pass to remove accidental noise. Accept the remaining family of extrapolations.
>
> The topological constraint — every new branch must remain continuously connected to the core — prevents unconstrained free-association without requiring a numerical weighting function.
>
> #### Architectural implication for the generation step
>
> The seven generation heuristics are reframed as environment-selection functions, not candidate-production functions. Each heuristic selects or constructs a generative environment whose topology makes certain associations more probable. The candidate emerges from dwelling in that environment rather than being manufactured by the heuristic directly.
>
