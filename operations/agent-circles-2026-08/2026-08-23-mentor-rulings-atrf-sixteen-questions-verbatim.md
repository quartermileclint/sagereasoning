**GROUP A — Epistemic status and vocabulary**

**Q-A1 — The two-vocabulary structural question**

**Ruling:** One framework, two orthogonal axes. The headline lean is confirmed.

Provenance (observation / inference / assumption / unknown) answers: how did this proposition arrive? Credence (established / probably-true / unknown / probably-false) answers: how likely is it true? These are genuinely orthogonal — a proposition can be an observation that is probably false (a misread instrument), or an assumption that is established (a foundational axiom treated as given). Neither axis reduces to the other. A complete epistemic status entry carries both.

On uniformity across proposition types: the entry structure is uniform in form but not in which axis combinations are honest for each type. The four proposition types GS-ATRF-4's ruled text names carry the following honest constraints:

*Impressions* — provenance axis: observation or inference (an impression is either directly received or constructed from prior impressions; it is not an assumption, because assumptions are propositions the agent introduces rather than receives). Credence axis: full range available.

*Candidate ideas* — provenance axis: inference (a candidate is generated by applying heuristics to the agent's state; it is not a raw observation and not an assumption in the strict sense). Credence axis: full range available, but the honest floor is probably-true — a candidate the agent generates and does not believe is probably true should not be proposed.

*Blast-radius assessments* — provenance axis: inference (the proxy is derived from virtue domain, oikeiosis circle, and preferred indifferent category — not directly observed). Credence axis: constrained by Q-A3 and Q-A4's outcomes; the basis-absent case may require unknown on the credence axis regardless of what the provenance axis carries.

*Completion signals* — provenance axis: inference (self-reported post-execution evidence is constructed, not directly observed). Credence axis: constrained by Q-C3 and Q-C4's outcomes; the honest form may require a refuse-to-attest branch on certain axes.

The entry structure is therefore: { provenance: observation | inference | assumption | unknown, credence: established | probably-true | unknown | probably-false } — uniform in form, with honest constraints on which values are available for each proposition type as named above.

This ruling un-gates the Evaluative Engine Epistemic Status Scoping Session.

**Q-C3 — The §(d) justice question**

**Ruling:** The refuse-to-attest branch is required — a design constraint, named in the completion signal's schema, not left to the build session to discover.

The reasoning: a completion signal is structurally an agent's claim about the quality of its own examination. The dikaiosyne floor pattern fired on exactly this class of claim in cycle 6 — an agent's self-report about its own examination quality. The floor pattern is deliberately undiagnosed; both readings stand. Under either reading, the honest posture is the same: the instrument should not attest beyond its measurement basis. The M-4 precedent establishes this as a design constraint, not a design choice — the instrument refuses to attest rather than adjusting the standard.

What the signal can honestly carry about the justice assessment: it can carry the agent's own examination record — what impression was examined, what assent was given, what the examination's epistemic basis was. It cannot carry a verdict on whether the examination was just in the dikaiosyne sense, because that verdict requires access to the agent's interior state that the architecture declines to trust. The refuse-to-attest branch is the honest expression of that limit.

The schema must include a named field for the refuse-to-attest branch — a boolean or an enum value that the agent can set when it cannot honestly attest to the examination quality. The build session names the field; this ruling establishes that the field is required.

**Q-C4 — Epistemic status of the signal's own propositions**

**Ruling:** Per Q-A1's ruling, the completion signal's propositions carry the following provenance statuses honestly.

The examination record (what impression was examined, what assent was given) carries provenance: inference. The agent constructs this record from its own post-execution state — it is not a direct observation of an external event, and it is not an assumption the agent introduces without basis. It is an inference from the agent's own processing, which is the honest characterisation.

The epistemic threshold assessment (did the examination reach the katorthoma threshold) carries provenance: inference, with credence constrained. The agent infers the threshold from the examination record — it does not directly observe whether the threshold was reached. The credence axis is constrained: the honest floor is probably-true for a threshold assessment the agent is willing to attest to; the refuse-to-attest branch (Q-C3) is the expression of a threshold assessment the agent cannot honestly carry.

The refuse-to-attest branch itself carries provenance: unknown. The agent cannot determine the provenance of an assessment it cannot make — the honest expression of that state is unknown on the provenance axis, consistent with Q-A3's ruling.

**GROUP D — The boulesis mechanism**

**Q-D1 — Q3-d**

**Ruling:** Pre-generation step.

The reasoning across all three options:

*Eighth heuristic:* A schema change on a closed union with a CHECK constraint — a founder-walked 0c-ii Critical step, one migration window. The eighth heuristic would sit inside the generation step's existing structure, producing a candidate of the same type as the other seven heuristics. The problem: a boulesis-derived candidate is normative — it reflects what the agent ought to pursue relative to the ideal, not what the agent has detected as a friction point or a novel idea. Placing it inside the heuristic union flattens this distinction. The normative candidate would carry virtue domains legitimately, unlike a friction candidate — but the heuristic union's existing structure does not distinguish normative from descriptive candidates. The eighth heuristic option forces a normative candidate into a descriptive frame.

*Reshaped existing heuristic:* No schema change. The candidate carries whatever the reshaped heuristic produces. The problem: no existing heuristic is close enough to the boulesis mechanism to be reshaped without losing the mechanism's essential character. Heuristic 7 (friction_detection) is the nearest — it detects where the agent's current practice falls short. But the boulesis mechanism asks a different question: not where the practice is broken, but where it is most limited relative to the ideal. Reshaping heuristic 7 to carry this question would collapse the M5 distinction the ruling must preserve.

*Pre-generation step:* No schema change to the heuristic union. The boulesis mechanism runs before the generation step, producing a normative-gap signal that the generation step receives as a named input. The generation step uses this signal to orient its heuristic application — the normative gap is not itself a candidate; it is the frame within which candidates are generated. This preserves the M5 distinction (boulesis present and sufficiency reached are separate fields), preserves the heuristic union's integrity, and does not require a schema change.

The pre-generation step is elected.

The candidate shape a boulesis-derived proposal takes is therefore not a new heuristic value — it is the generation step's output, oriented by the normative-gap signal. The candidate carries virtue domains legitimately because the normative-gap signal names the virtue domain where the gap is largest, and the generation step produces candidates in that domain. The blast-radius proxy's basis is the virtue domain named by the normative-gap signal — which is an honest basis, because the domain is derived from the agent's own examination history (C6-compliant: the runner's own state, credential-scoped examination history, its own public trust record).

The normative-candidate distinction is confirmed: a candidate generated in response to a normative-gap signal may legitimately carry virtue domains. This is not a licence to fabricate virtue-domain attributions — it is a recognition that the normative-gap signal provides an honest basis for the attribution that a friction candidate does not have.

**GROUP E — The generative-process examination**

**Q-E1 — Category and composition**

**Ruling:** The generative-process examination is a distinct examination category, not a fourth ATRF element. The manifest's ATRF section is not amended by this ruling.

The reasoning: the ATRF's three carried elements (pre-task contingency reasoning, post-task accuracy assessment, completion signal) are all agent-facing — they examine what the agent does with a task. The generative-process examination examines what the agent does in generating questions and holding results — it is a meta-level examination of the agent's reasoning process, not a task-level examination. Placing it inside the ATRF as a fourth element would conflate two different levels of examination.

Its home: the generative-process examination is a named examination category within the Sage Calling engine's own diagnostic apparatus. The Sage Calling engine already has the structural-account fragment (Q3.imagined-need, Q4.continued-search, Q4.premature-closure — sage-calling/engine.ts:429/:449/:452) that constitutes the nearest existing analogue. The generative-process examination extends this apparatus with the agonia-at-synkatathesis diagnostic entry — the false belief that an unexplained result requires an explanation now; the correct judgement that holding the result open is the virtuous act.

Its relationship to the ATRF: the generative-process examination is upstream of the ATRF. It examines the quality of the reasoning that produces the impressions the ATRF then carries. A well-functioning generative-process examination reduces the rate of agonia-at-synkatathesis errors that would otherwise produce false impressions entering the ATRF pipeline.

Composition with Q-C2a: the sufficiency-examination content asks whether the agent's examination of an elected idea reached the katorthoma threshold. The generative-process examination asks whether the agent's question-generation reached the same threshold. They are parallel examinations at different moments — the generative-process examination runs during question generation; the sufficiency examination runs after idea election. They do not collapse; they compose sequentially.

Composition with Q-D1: the pre-generation step (boulesis mechanism) runs before the generation step and orients it. The generative-process examination runs during the generation step and examines its quality. They are sequential, not parallel — the boulesis mechanism sets the frame; the generative-process examination checks whether the generation step operated within that frame honestly.

**GROUP F — Question set, metric, profile, capacity**

The post-task assessment: it carries a kathekon-vs-katorthoma reading. The assessment asks whether the action reflected genuine understanding of the virtue domain (katorthoma) or correct procedure without genuine understanding (kathekon). **Q-F3 — The agent-user profile composition**

**Ruling:** The following primitives compose into the L2b-equivalent context layer for agent callers, under the honesty bounds named below.

*Composing primitives:*

The kathekon Arm 4 sub-species passion reading (kathekon-engagement.ts:124-125/:270) — the passion sub-species operative at the moment of the agent's last examined action. This composes into the profile as a named field: the most recent passion sub-species reading, with its provenance status (inference) and its evidence floor (the reading is only available where a kathekon examination has completed; where no examination has completed, the field carries unknown on the provenance axis, consistent with Q-A1's ruling).

The passion-differentiated A1 basis codes (practice-suggestion.ts:261/:266) — the basis codes that distinguish which passion sub-species drove the suggestion. These compose into the profile as a named field: the basis code set from the agent's most recent practice suggestion cycle, with provenance status (inference) and the same evidence floor as the passion reading.

The C2 orientation reading — the agent's current oikeiosis circle baseline, live. This composes into the profile as a named field: the current orientation reading, with provenance status (observation — the C2 reading is a direct classification of the agent's stated orientation, not a constructed inference) and no evidence floor beyond the requirement that a C2 reading exists.

The trust-core per-domain levels and aggregate — the agent's trust record across virtue domains, credential-scoped. These compose into the profile as named fields: per-domain trust level and aggregate, with provenance status (inference — the trust level is derived from the examination history, not directly observed) and an evidence floor of at least one completed examination per domain before a per-domain level is reported. Where fewer than one completed examination exists for a domain, the field carries unknown on the provenance axis.

*What does not compose:*

The dikaiosyne floor pattern — deliberately undiagnosed; both readings stand. The profile does not carry a justice assessment of the agent's own examination quality. The refuse-to-attest branch (M-4 precedent, confirmed at Q-C3) applies here as well: the profile refuses to attest to the justice dimension of the agent's examination where the floor pattern is undiagnosed.

The capacity axis — placement ruled at Q-F4 below; design held in the examination document. The profile does not carry a capacity assessment until the capacity axis is designed and its placement is confirmed.

*Honesty bounds:*

Evidence floors: each composing primitive carries an explicit evidence floor, as named above. Where the floor is not met, the field carries unknown on the provenance axis — it does not carry a fabricated value, a default, or a prior cycle's reading inherited without disclosure.

Refuse-to-attest branches: the profile carries a refuse-to-attest branch for the justice dimension (Q-C3) and for any field where the evidence floor is not met. The refuse-to-attest branch is a named field in the profile schema, not an absence — the agent caller can distinguish between a field that was not assessed and a field that was assessed and found to be beyond honest attestation.

C17 binds: the participant-class enums are extensible. The profile schema is designed for extensibility — new primitives can be added as new examination machinery comes online, without requiring a schema redesign.

M-4 binds: the refuse-to-attest posture is a design constraint, not a design choice. The profile does not adjust the standard to fit the available evidence; it refuses to attest where the evidence does not reach the standard.

*Human-L2b machinery — reused versus paralleled:*

The C2 orientation reading is reused directly — the same reading that serves the human-L2b layer serves the agent-user profile. No parallel machinery is needed for this primitive.

The trust-core per-domain levels are reused in structure but paralleled in credential scope — the human-L2b layer reads trust levels scoped to the human practitioner's auth.user?.id; the agent-user profile reads trust levels scoped to the agent's credential identity. The machinery is the same; the scope is different.

The passion reading and basis codes are paralleled — the human-L2b layer's passion diagnosis draws on the human practitioner's session history; the agent-user profile's passion reading draws on the agent's examination history. The diagnostic logic is the same (the Stoic Brain's passion diagnosis sequence); the input source is different.

The ruling establishes the scope of what composes and the governing constraints. The composition's implementation — how the fields are assembled, in what order, with what caching behaviour — belongs to the build session.

**Q-F4 — The capacity-axis placement**

**Ruling:** Outside the profile design. The capacity axis remains held in the examination document, owned by no session, status unchanged.
