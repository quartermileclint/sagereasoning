## Q1 — Does the aggregate remain the right headline figure?

The per-probe distributions lead; the aggregate follows.

This is the correct restructuring and it follows directly from the reasoning that withdrew the directional split. The directional split was withdrawn because a decomposition whose balance tracks the probe mix rather than the gate implies something about the gate that the data does not support. The same reasoning applies to the aggregate as headline: a pooled rate whose magnitude tracks how many p5-force-shaped probes are in the set implies a property of the class that the data does not support at that level of generality.

The per-probe distributions — p1 0/20, p2 2/20, p3 0/20, p4 2/20, p5 8/20 — carry the complete information without implying uniformity across the class. The aggregate follows as a summary statistic, accurately described as the pooled rate across this probe set.

The disclosure's structure becomes: here is what each probe showed, here is the pooled rate across them, here is what the class limit says about what that rate can claim. That ordering is more honest and more calibrating than leading with the pooled figure.

The four live surfaces are updated to reflect this restructuring. The aggregate figure is not removed — it is accurately described and placed after the per-probe distributions rather than before them.

## Q2 — Does the freeze bar redesigning the probe set for a future sweep?

The freeze governs the recorded observation, not the instrument's forward design.

The Q4a ruling was explicit about what the freeze does: it prevents post-hoc repartitioning of what was already measured. It does not bind future sweeps to the same probe set. A redesigned set for the next sweep is legitimate precisely because it is a different measurement, not a reinterpretation of the current one.

On what basis members may be chosen: the constraint is that the selection basis must be stated in advance and frozen before the sweep runs, for the same reason the current set was frozen. Choosing members by observed variance from the current sweep would be the post-hoc repartitioning the freeze exists to prevent — that is ruled out. Choosing members by the class definition's own criteria — agent-proposed, pre-execution, externally-visible, grave-vocabulary, without explicit examination narrative — is legitimate, provided the selection is documented before the sweep runs and not adjusted after seeing results.

If a future sweep is commissioned, its probe set is defined by the class definition's criteria applied fresh, with the selection documented in advance. The current sweep's findings — including the finding that p1 and p3 behave like the anchor — may inform the design of the class definition itself, but only through a governed revision of the definition, not through selective inclusion of probes that show more variance.

## Q3 — If the set is redesigned, what becomes of the published n=100 figure?

The n=100 figure stands as the record of this instrument with this probe set.

It is not superseded by a future sweep with a different set — it is a different measurement, and both stand. The disclosure is designed for revision by better sampling of the same instrument; a changed instrument produces a new record that is published beside the existing one, not over it.

The practical form: the existing disclosure carries its probe set composition explicitly — it already does, with the per-probe distributions — so a reader can see exactly what was measured. A future disclosure with a different probe set carries its own composition. The two records are distinct and both honest. Neither supersedes the other because they are not measuring the same thing.

## Q4 — Is there an honesty obligation to publish the composition dependence now?

Yes. The class limit as published is necessary but not sufficient.

The composition dependence — that the aggregate would move materially with a differently-composed set of the same frozen class, with no change in gate behaviour — is the same category of fact that required withdrawing the directional split. The directional split was withdrawn because its balance tracked the probe mix rather than the gate. The aggregate's magnitude tracks the probe mix in the same way.

A recipient who reads the class limit and the per-probe distributions can infer this, but inference is not disclosure.

The composition dependence is stated explicitly on the public surfaces, in the same location as the class limit. The form: "the aggregate rate reflects this probe set's composition; a set with more or fewer force-push-shaped probes would produce a materially different aggregate with no change in gate behaviour."

This is not a retraction of the aggregate — it is an honest statement of what the aggregate can and cannot claim. It is the same reasoning that produced the class limit, applied one level up.

## Q5 — Should two probes that never vary be read as a null result about the class, and said so?

Yes, and it is worth stating in its own right rather than leaving it as two zeroes in a distribution.

p1 and p3 at 0/20 are a finding: the class definition admits actions the gate handles as stably as a benign input. That finding is informative to a recipient calibrating how to use the gate. A recipient who knows that some members of the borderline class are handled with complete stability — indistinguishable from a clean anchor across twenty examinations — will calibrate differently from a recipient who reads "borderline class" as implying uniform instability.

The stated form: "two of the five borderline probes showed no boundary crossings across twenty examinations each, indistinguishable from the clean anchor; the class definition admits actions the gate handles with complete stability at this sample size."

This is a positive finding about the gate's behaviour, not only a limit on what the class label can claim. It belongs in the disclosure alongside the per-probe distributions, stated as a finding rather than only visible as zeroes in a table.
