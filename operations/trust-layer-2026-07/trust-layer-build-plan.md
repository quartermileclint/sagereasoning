## Phase 1 — The trust core, measure mode (4 sessions, server-side)

### S1 — Trust state + event vocabulary (code-critical: new schema + data rights)
New store: per-`(agent_id, domain)` trust levels (proximity-scale-valued, per mentor spec 4) + typed **trust events**: credential-completed (∝ domain match × coverage continuity), reflect-completed-honest (stability > episodic quality), justice-surface-transparently-handled (highest single positive event), credential-suspended/revoked, passion-unflagged-by-self-screen, justice-surface-unevaluated (**floors the domain at deliberate until a demonstrated evaluation**), orchestrator-proceeds-under-habitual-flag (A8 — degrades the orchestrator's oversight domain), delegation-reflection cases 1/2/3 (A9 — moderate-oversight / oversight+dikaiosyne / flag-only, capacity-proportional). **Decay** per A3: deployer volatility rating (low/moderate/high → 12/6/3-month decline onset), floors at the profile prior never below, reflect-modulation capped at half-rate. R17 extension: trust records erasable (delete/erase/export routes + retention); K1 identity; consumer-unforgeable server-side composition (R18f-parallel: no trust event without verifiable examination artifacts).

### S2 — Evidence weighting + verdict confidence (code-elevated, deterministic lib)
Mentor A5's seven confidence tiers as a pure function — **Depth > Signature > Corroboration > Recency, multiplicative, weakest dimension sets the ceiling**. Mentor A2's domain-distance rule: deployer-defined function-type taxonomy, each type carrying a 4-virtue-domain weight profile; distance = Σ|Δweights|; per-dimension credential transfer; **zero-confidence floor above the deployer threshold, enforced so a zero-confidence credential can never contribute to a proceed verdict**. Tier-1/2/3 evidence weighting (credential > behavioural condition-matched > profile prior) + the justice-surface modifier.

### S3 — Multi-source combiner (code-elevated → Critical at wiring)
Mentor A1 exactly: default tasks → deterministic engine authoritative (no parallel LLM); justice surfaces pre-corroboration → second-reader LLM on the obligation field only (agree → deterministic stands; conflict → pause-and-escalate); post-corroboration → deterministic primary on corroborated fields, LLM supplementary on uncorroborated fields with explicit low-confidence marking; **conflicts always pause, never average**. Within-session supersession reuses the live CI-4 marker semantics; cross-session = weighted recency per-domain (domain evidence only updates its domain).

### S4 — Intervention policy engine, MEASURE mode + transparency tracking (code-elevated dark; enforce = later Critical)
