**Q2 — May two windows overlap on the same records?**

No. A record belongs to exactly one window. The ruling is as the relay recommends.

A new window's clock starting closes the prior window's intake, even where the prior window's clock has not yet run out. The buffer is continuous and every future window will be carved from it — the ruling must be general, not specific to Q1's answer.

The alternative — shared records — makes each window's composition disclosure describe a population it shares with another window. That is the same class of error Q-S1 identified when it found that describing two windows as one obscures the composition of each. A composition disclosure that names records belonging simultaneously to two windows is not a disclosure — it is a description of an overlap that neither window's analysis can cleanly separate.

The practical implication for Q1: R11's records belong to the current window, which closed its clock at three of four. They do not belong to W2. W2's first record is the first consult record of the sitting the founder opens after this ruling.

**Q3 — Is a provenance-triggered stratum a legitimate live trigger?**

No. It is a category error. The relay's recommendation is correct and the reasoning is confirmed.

A live policy that examines previously-rejected inputs harder selects on the measured variable. Under worst-of-K, where any floor blocks and no rejection can recover, it ratchets: an input rejected once is sampled harder, so is more likely to floor again, so is sampled harder still. That is not a floor applied to an input with known adverse history. It is a feedback loop that amplifies the initial classification regardless of whether the input's actual character has changed.

The relay asks whether Q-R11-A1 has settled the trigger class generally. It has not settled it formally — a provenance trigger is a different trigger from a first-draw signal trigger, and Q-R11-A1 addressed the latter. But the same reasoning reaches it: a trigger is admissible only on a measured relation between the trigger signal and the latent floor. Provenance — prior rejection — is not a measured relation to a latent floor. It is a record of a prior classification. Under W, that prior classification is already operative: the input was rejected. Sampling it harder on the basis of that rejection adds nothing to the gate's accuracy and introduces the ratchet. The trigger class is not settled generally by Q-R11-A1, but this specific trigger is ruled out on the same grounds.

**Q4 — Can a confidence signal be designed before the near-boundary population is measured?**

No. The relay correctly identifies that three rulings reach this from different directions without addressing it head-on. The ruling addresses it directly: no confidence signal is admissible on a sampled verdict before the near-boundary population is measured and a signal-to-variance relation is established.

This holds on all three grounds simultaneously. Q-S2 ruled the near-boundary gap not closed. Q-M8 forbids a confidence scalar on a sampled verdict. The Prerequisite Criterion rules against a design producing an output that resembles confidence without building the prerequisite. A confidence signal derived from an unmeasured relation satisfies none of these and violates all three.

Option C is unavailable until Deliverable A's cross-tabulation exists and shows a measured relation between a first-draw signal and whether the input carried a latent floor. No first-draw signal is admissible on doctrine alone as a basis for a confidence output.
