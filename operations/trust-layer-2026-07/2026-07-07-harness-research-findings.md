## 1. The channel law is measured industry consensus

What SageReasoning derived first-hand at Gate-1 Slice 5b (out-of-band binds; injected advice is discounted) is now stated independently across the industry with measurements: policy-in-prompt cuts violations only ~95%→41% with 25–85% cross-model variance; a pre-action-authorization red-team CTF went from 74.6% attacker success to 0% with deterministic interception; Microsoft's Agent Governance Toolkit phrases it "actions the kernel denies are not unlikely — they are structurally impossible." Anthropic's own auto-mode approval classifier is deliberately **reasoning-blind** (strips the agent's justification so it cannot talk the gate into a bad call). "Harness" is now an industry noun (Microsoft shipped a literal "Agent Harness" at BUILD 2026; arXiv work reverse-engineers Claude Code's harness — ~98.4% of its codebase is harness code, 1.6% decision logic). Design consequence: every load-bearing control is classified by channel before it is trusted; judges and self-critique are inputs, never gates.

## 2. Build-vs-inherit per the seven layers

**INHERIT (commodity, mature):** Execution — OS/container sandboxes (Seatbelt, bwrap+seccomp/Landlock, Docker, E2B/WASM). Lifecycle — durable execution (Temporal/Restate/Inngest; LangGraph checkpointer+interrupt()+Command(resume) in-framework); approvals as durable events; LLM outputs recorded once and replayed. Observability — OTel GenAI semantic conventions (agent/tool/workflow spans; still experimental status) + any backend. Governance vocabularies — policy languages (OPA/Rego, Cedar), identity standards (SPIFFE/DID). Context — memory products (Mem0/Zep/Letta), compaction patterns; injection defense is a harness-level provenance-and-privilege problem (CaMeL control/data-flow split; MCP tool-poisoning is a mass-scale attack class — OWASP ASI06).

**BUILD (where the trust claims live; no framework supplies the semantics):** the tool-call interception chokepoint + action-risk classification (reversible/irreversible; path-history-aware); the binding-channel wiring; **signed, tamper-evident verification records that never trust agent self-report** (the judge-gaming literature — RLVR models overwrite tests, monkey-patch scorers, fool judges with fabricated self-assessments — independently confirms the extraction-trust locus); idempotency keys + receipts on mutating tools; honest attestation semantics. This build-list is exactly SageReasoning's existing asset base.

**Framework reference points:** LangGraph interrupt() is binding via checkpointer; OpenAI Agents SDK guardrail tripwires raise (binding) with tool-level guardrails; Google ADK before_tool_callback/Plugins is the cleanest published binding-vs-advisory doctrine; CrewAI is the cautionary tale (post-output validation only; pre-tool authorization still open); Microsoft Agent Framework 1.0 (AutoGen+SK merged) ships approval middleware + plan/execute modes.

## 3. The whitespace: nothing attests reasoning quality

Every 2026 trust rail attests **identity** (A2A v1.0 signed Agent Cards — Linux Foundation, 150+ orgs, ACP merged in; SPIFFE SVIDs; W3C Agent Identity Registry CG; Cubitrek Agent Passport; Okta/Auth0 XAA), **authority** (MCP OAuth 2.1 + Resource Indicators; mandates/AP2; scoped payment tokens), or **outcomes** (ERC-8004 on-chain reputation — Sybil-acknowledged; marketplace ratings — fake-review migration documented; eval leaderboards — ~19.8% of top SWE-bench "solved" entries semantically incorrect). The Agent Passport spec **concedes the gap in writing**: reasoning quality is excluded — "the verifier cannot detect this directly." A2A discovery has **no quality signal at selection time** (the discernment protocol's exact slot). Guardrail products (GA Guard, NeMo, Llama Guard, Lakera, Bedrock; Aport pre-action auth with signed Ed25519 decision records) check content/policy conformance — explicitly NOT ethical justification, third-party effects, or justice. The academic frontier names the WHY-record gap ("why-trails", reasoning provenance, verifiability-first agents) but ships nothing signed/portable. **The unoccupied position: a portable, cryptographically verifiable, per-decision credential of reasoning quality — examined-before-acting, justice structure over affected circles, reproducible-from-signed-bytes — issued against an honest, disclosed gaming ceiling.** SageReasoning's signed Layer-2 assessments + examination_mode + accreditation GET already prototype it.

**Interop rails to ride (design-for, ship native per the founder's election):** A2A Agent Card extension for discovery-time surfacing; W3C VC/DID-mappable credential shape; OTel GenAI spans referencing signed assessments; MCP OAuth transport patterns (the bearer UPC already matches). **Regulatory clock:** EU AI Act high-risk obligations bind 2026-08-02 — Art 12 designed-in automatic logging, Art 14 human oversight, FRIAs (the closest regulatory analogue to justice-toward-non-consenting-parties); "in a chain of AI agents, the compliance boundary extends to every agent performing a high-risk function." NIST AI Agent Standards Initiative ships an interoperability profile + test suite Q4 2026. **Adjacent plays:** AIUC-1 insurance-backed org-level certification (complementary — per-decision evidence could feed its audits); the ERC-8004/KYA decentralized-reputation stack (gamed); the pre-action-authorization class (Aport et al. — owns the runtime seat, scores policy conformance not reasoning quality).

## 4. The Anthropic-native control surface (for the reference harness)

Hooks: 20+ lifecycle events; **PreToolUse is the only binding pre-action gate** (permissionDecision allow/deny/ask/defer + input modification; exit-code-2 blocking); Stop can force a turn (decision:block); PostToolUse observes + injects context but cannot block; UserPromptSubmit can block; hooks never see model-internal reasoning; deny rules take precedence over everything; most-restrictive wins across parallel hooks. Agent SDK exposes the same events as in-process async callbacks (canUseTool/permission callbacks) for an owned-loop harness; sandboxing binds Bash at the OS level (filesystem + network allowlists); plugins/skills are the distribution channel (auto-load from .claude/skills); managed settings give org-immutable policy. Hard limits to design around: PostToolUse cannot block; SessionStart/End cannot block; sandbox covers Bash only; hook visibility is tool/action-scoped.
