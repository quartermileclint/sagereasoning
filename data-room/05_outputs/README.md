# 05 — Outputs (empty until the manual loop runs)

This folder holds **test-run results and observations**. It is intentionally empty at room build — the room build (Steps 1–6) defines *what* to test; it does not *run* the test.

It fills in the follow-on session (Step 7 — one manual founder-verified loop, PR1 single-loop-proof / 0g manual-first):

- One **human-practitioner** journey result (0h criterion 4).
- One **agent-developer** journey result (0h criterion 4).
- The per-seam **pass / fail / gap** record (including the Combination-1 gap, recorded against `04_test_brief/` A.2).
- The first **golden output** to diff future runs against (`99_review/missing-context.md` M-3).

Every result is compared against the known-good baseline in `00_baseline/`.
