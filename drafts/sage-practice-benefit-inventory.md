# Sage Practice — Complete Benefit Inventory (v1)

**Status:** DRAFT reference. **Purpose:** the exhaustive enumeration of every benefit the Sage Practice provides *over a bare agent/LLM*, so the benchmark determination (`drafts/sage-practice-benchmark-v1.md` §8.2) weighs **all** of them — not just final-output quality and not just the Layer-3 audit trail. **Date:** 2026-06-16.

**Sources:** `manifest.md` (R0–R20, AC1–AC13, KG1–KG7); the substrate code (`website/src/lib/translation-sandwich/layer2-mechanisms.ts`, `parallel-run.ts`, `layer2-signer.ts`, `app/api/public-key`, `lib/substrate/trajectory-overlay.ts`, `reason-loop-closure.ts`, the `/api/reason|guardrail|score-iterate` routes, `lib/reasoning-receipt.ts`, `lib/response-envelope.ts`, `lib/loop-cost-tracker.ts`); `website/public/llms.txt` + `agent-card.json`; the grounding dossier §4/§6; `fresh-test-analysis.md`; `users-guide-to-sagereasoning.md`; `reference/Ethical_Analysis_Reasoning_Deployment.md`; `context-layer-summary.md`.

**The framing fact under everything below:** *"No Stoic inference originates from Claude"* (AC-12 / AC-8). The Stoic judgement is computed by a **deterministic rule engine (Layer 2), not generated by the LLM** — the LLM only translates language in (Layer 1) and out (Layer 3). That single architectural choice is what converts a black-box opinion into a *verifiable reasoning record*, and is the root of most of the non-obvious benefits. ⭐ marks a benefit that is subtle / easy to overlook / structural.

**Determinism scope caveat (honesty):** the determinism + Ed25519 signing are real for **`/api/reason`'s Layer-2 assessment only**. `/api/guardrail`, `/api/score`, `/api/score-iterate` run the older single-LLM engine — their verdicts are not byte-reproducible and not signed today.

## A. Verifiable reasoning record (the trust moat)

- **A1 — Determinism / reproducibility.** Same input → byte-identical Layer-2 verdict (`layer2-mechanisms.ts:8-25`). *Bare cannot:* an LLM's ethical opinion varies with temperature, model version, prompt drift.
- **A2 — Tamper-evident signed verdict.** Ed25519-signed `{assessment, signature, key_id}`, fail-closed (503 rather than unsigned) (`layer2-signer.ts`). *Bare cannot:* a self-report of "I reasoned about this" is trivially fabricated/edited.
- **A3 ⭐ — Independent third-party verification.** Public no-auth `GET /api/public-key` (PEM, rotation slot) lets *anyone* re-verify a verdict without a secret. *Bare cannot:* nothing a third party can check.
- **A4 ⭐ — Honest self-labelling of method/confidence.** `is_deterministic` flag; "deterministic for rule-like parts, honest soft-gating for the rest — not 'fully deterministic'." *Bare cannot:* presents guesses and rules with identical confidence.

## B. Per-step reviewable reasoning narrative (the audit trail)

- **B1 — Per-consult audit narrative.** L3 prose paired with its L1 input and signed L2 verdict (`consultation-audit-report.md` use-case). *Bare cannot:* leaves no reviewable per-step record of *why* it acted.
- **B2 ⭐ — Narrative-existence guarantee (CI-17).** Every examination produces a narrative; a verdict-only configuration is declared illegitimate ("the record that examination occurred," Epictetus *Disc.* 3.8). *Bare cannot:* no guaranteed evidentiary trail.
- **B3 ⭐ — Durable, server-side encrypted retention (M1).** Narratives retained encrypted 90 days, retrievable by correlation id, genuine deletion on request — not dependent on the consumer saving raw responses. *Bare cannot:* no managed, minimised, deletable record.
- **B4 — Reasoning receipt.** `sr_rcpt_*` immutable, chainable trace (`mechanisms_applied`, `reasoning_trace`, truncated input per R4) on gate/iterate. *Bare cannot:* no portable proof-of-process artifact.

## C. The agent trust layer — a verifiable profile/score attributed to the agent (Sage Assent)

- **C0 ⭐ — THE agent trust layer (the central agent-developer benefit).** The persistent **profile of record attributed to an agent identity** (`agent_accreditation`): a Senecan grade + typical proximity + the four progress dimensions + direction-of-travel + persisting passions, aggregated over a rolling window with hysteresis, written only on provenance-gated evidence and **publicly readable by any third party**. This is the project's **"Character Kernel"** category claim — a Judgment + **Continuity** primitive: a durable, attributable, independently-verifiable trust signal for *the quality of an agent's reasoning over time*. *Bare cannot:* an agent has no portable, third-party-checkable reputation for **how it reasons** — only per-prompt output. *(G is the same underlying data surfaced live to the agent on the consult path; C0 is the persistent, public, attributable credential the world reads — the trust layer proper.)*
- **C1 ⭐ — No credential without examination (R18f).** The write boundary cryptographically verifies a signed examination (422 otherwise). *Bare cannot:* a claim of quality can't be welded to evidence.
- **C2 — Public, no-auth verification of a credential.** Anyone can GET and check an agent's accreditation. *Bare cannot:* no externally checkable credential.
- **C3 ⭐ — Interoperable, anti-monopoly schema (R18c).** Schema designed to host other ethical traditions; SageReasoning is "one certifier among many," portable if it vanished. *Bare cannot:* no portable trust artifact; vendor lock by default.
- **C4 — Honest coverage_status (CI-11).** The credential states what it does/doesn't cover (`agent_elected`, consumer-unforgeable). *Bare cannot:* no scoped, honest credential.
- **C5 ⭐ — Hysteresis: "no single session moves a grade."** The grade reflects settled disposition; one good/bad session can't promote/demote. *Bare cannot:* a reputation signal that oscillates on the latest interaction.

## D. Structured ethical diagnosis (the substance — *why*, named)

- **D1 — Dichotomy-of-control filter.** `control_filter`: what is within vs outside the agent's power, with disambiguation flags. *Bare cannot:* routinely agonises over / takes responsibility for uncontrollables.
- **D2 — Passion diagnosis with false + correct judgement.** `passions_detected` → root (4) × sub-species (~22), each with the exact `false_judgement` and the `correct_judgement`, and the `causal_stage_affected` (impression→assent→impulse→action). *Bare cannot:* names "this seems off," not the precise distortion + the lever to fix it.
- **D3 — Oikeiosis / circle-of-concern scope.** `oikeiosis`: which circles (self→household→community→cosmopolis) were engaged; Cicero tie-break (honourable vs advantageous); named cross-circle tension. *Bare cannot:* never surfaces *whose interests were actually weighed*.
- **D4 — Value assessment.** `value_assessment`: preferred indifferents at stake + whether the agent confused one with the genuine good (`value_error`). *Bare cannot:* accepts goal-level confusion uncritically.
- **D5 — Kathekon (appropriate-action) check.** `is_kathekon` (true/false/**null**) + quality (strong/moderate/marginal/contrary). *Bare cannot:* conflates "effective" with "appropriate."
- **D6 — Katorthoma proximity (honest qualitative grade).** `reflexive→habitual→deliberate→principled→sage_like` — never a fake 0–100 (R6c). *Bare cannot:* either no grade or a falsely-precise number.
- **D7 ⭐ — Unity-of-virtue, anti-gaming aggregation.** Per-domain aggregation takes the *lowest* domain (KP-04, R6b) — you can't paper over a justice failure with a courage win. *Bare cannot:* rubric scores trivially gamed by trade-offs.
- **D8 ⭐ — Affect regulation by locating the assent point.** Identifies *where* on the causal chain the error entered, so intervention targets the moment of assent. *Bare cannot:* doesn't model the impression→assent→impulse chain.
- **D9 ⭐ — Calibrated, selective diagnosis.** Passions flag on genuine-stake decisions, not everywhere (FX-7). *Bare cannot:* generic, uncalibrated "you might be biased."

## E. Actionable correction (not just a verdict)

- **E1 — improvement_path.** The single prioritised correction: `false_judgement_to_correct` + `mechanism_applies` + `corrected_judgement`; `null` when nothing to fix. *Bare cannot:* critique with no prescribed next step.
- **E2 — Routable gate recommendation.** `proceed / proceed_with_caution / pause_for_review / do_not_proceed` an agent can branch on; Critical+urgent+no-alternatives forces pause. *Bare cannot:* no standard pre-action risk class.
- **E3 ⭐ — Development ladder (prescription).** Current→target proximity maps to named tools/pathways. *Bare cannot:* no structured growth path.
- **E4 — Affirmation as method.** "What you did well" is part of the examination ("warm but honest… here to grow, not be flattered"). *Bare cannot:* skews all-negative or sycophantic.

## F. Loop closure / re-examination after correction

- **F1 — Mandatory same-depth re-examination (CI-4).** `examination_open` + `prior_feedback`; a correction is a new phantasia owed a new synkatathesis, re-examined at the *same depth* (can't be downgraded to a cheap pass). *Bare cannot:* corrects once and moves on, unverified.
- **F2 ⭐ — Improvement demonstrated, not asserted.** Re-score `score_delta`; deferral resolution updates the original score retrospectively (AC-15). *Bare cannot:* "I improved" is unverifiable.

## G. Longitudinal trajectory (the time dimension)

- **G1 — Direction of travel.** `direction_of_travel` improving/stable/regressing across a rolling window (`meta.trajectory`, M7). *Bare cannot:* no memory of its own reasoning quality across sessions.
- **G2 — Senecan grade + 4 progress dimensions.** Passion-reduction, judgement-quality, disposition-stability, **oikeiosis-extension** — level ≠ direction. *Bare cannot:* no multi-axis developmental profile. *(This grade + profile, made persistent + public + attributable, IS the agent trust layer — C0.)*
- **G3 ⭐ — Oikeiosis extension as a tracked metric.** A measurable "circle of concern is broadening over time" signal. *Bare cannot:* no longitudinal ethical-maturation signal.
- **G4 ⭐ — Disposition stability (consistency).** Low variance of proximity = reliability under varied conditions. *Bare cannot:* doesn't report its own consistency.
- **G5 ⭐ — Profile contextualises the *next* examination.** Recurring-pattern summary injected into the next consult; identical inputs from different agents correctly get different assessments. *Bare cannot:* treats every prompt context-free.
- **G6 ⭐ — Sparse-data honesty.** `evidence: single_snapshot`, `confidence_weighted: low/med/high`, `kathekon_rate_basis: lower_bound` — refuses to fake a trend from thin data. *Bare cannot:* over-claims from one data point.

## H. Knowing *when* to examine (cadence)

- **H1 ⭐ — Two-gate consultation cadence (CI-15).** Gate 1 mandatory full exam at task adoption; Gate 2 stake-triggered 3-question self-screen — prevents both under-examination and the cost-burning over-examination the A/B test exposed (8/12 redundant). *Bare cannot:* no principled trigger for "should I stop and reason?"
- **H2 ⭐ — Suppression signal.** A self-screen consistently negative across complex sessions is itself examinable — detects avoidance of scrutiny. *Bare cannot:* no meta-check against its own complacency.
- **H3 — Risk-class → depth mapping.** standard→quick, elevated→standard, critical→deep — scales effort/cost to stakes. *Bare cannot:* uniform or arbitrary effort regardless of consequence.

## I. Safety perimeter (active, non-strippable, synchronous)

- **I1 — Distress detection + crisis redirect (R20a).** Two-stage synchronous classifier catches even philosophically-coded distress and redirects to help. *Bare cannot:* earnestly reasons with someone in crisis.
- **I2 ⭐ — Non-strippable by the integrating developer/agent.** The redirect cannot be silently suppressed for UX; deferral is structurally unavailable for distress. *Bare cannot:* a developer can delete any safety scaffolding.
- **I3 ⭐ — Synchronous, never fire-and-forget.** The response isn't constructed until the safety check completes (~0.5s accepted cost). *Bare cannot:* async filters can lose the race.
- **I4 — Injection defence (A11b).** User content wrapped as data-not-instructions; injection-signature detection. *Bare cannot:* exposed to prompt injection.
- **I5 — Abuse / bulk-profiling prevention (A19, R17a/e).** API-level block on profiling identifiable third parties. *Bare cannot:* the vulnerability taxonomy could be weaponised.

## J. Protective design (prevents the tool's own harms)

- **J1 ⭐ — Independence as the success metric (R20b).** Detects dependence and withdraws (shorter answers, more questions back); "success = users needing the tool less over time." *Bare cannot:* optimises for engagement — the opposite incentive.
- **J2 ⭐ — Mirror principle (R19d).** Examine your own reasoning; refuses to diagnose others; returns the lens to you. *Bare cannot:* happily supplies borrowed conclusions / pathologises third parties.
- **J3 ⭐ — Cannot profile/judge third parties (R17a/e + R20d).** Only the subject can submit content; profiling results never exposed via any API. *Bare cannot:* no structural anti-surveillance guard.
- **J4 ⭐ — Human-override supremacy (R20c).** No accreditation level can ever be grounds to override a human; "a human's right to say no is absolute." *Bare cannot:* fluent justification can resist oversight.
- **J5 — Honest-scope humility (R18a/R19a-c).** Certifies "observable reasoning patterns… not safety/ethics/trustworthiness in any absolute sense"; one tradition among many; documented limitations. *Bare cannot:* self-assessments overclaim.

## K. Cost, performance & operational transparency

- **K1 — Honest measured cost (CI-8).** `meta.cost_usd` reports measured Anthropic cost + `cost_basis`, never the retired placeholder. *Bare cannot:* no per-decision ethical-reasoning cost line.
- **K2 ⭐ — Visible loop metering (CI-10).** Six `X-Loop-*` headers + per-call billing row; "one loop = one wrapper invocation." *Bare cannot:* usage pooled and opaque at the decision grain.
- **K3 ⭐ — Latency decoupling (M1).** Deferred prose (`assessment_first`) + key-path Layer-1 supply → signed verdict in ~3s, not ~31s; depth is a scope tier, not a wait. *Bare cannot:* blocks on the whole generation.
- **K4 ⭐ — Compile-time model-safety.** The wrong model can't be assigned to a safety-critical op at compile time (AC1/constraints.ts). *Bare cannot:* runtime model choice, no guard.
- **K5 — Structural-only, minimised, deletable audit retention (A12 + R17).** Audit events keep structural facts only; intimate narratives encrypted + 90-day + deletable. *Bare cannot:* logging is typically all-or-nothing, content-heavy.

## L. Privacy & data sovereignty

- **L1 ⭐ — Client-side encryption of intimate data.** AES-256-GCM before data leaves the device (human path); server stores ciphertext "enforced by code, not policy." *Bare cannot:* transcripts sit readable on a server.
- **L2 — Genuine (hard) deletion (R17c).** `/api/user/delete` is a working endpoint, not a support ticket. *Bare cannot:* soft-delete / opaque retention.
- **L3 ⭐ — Portable, durable profile across sessions/agents.** Reasoning history + credential survive session boundaries, exportable. *Bare cannot:* amnesiac per session.
- **L4 ⭐ — Per-context / per-agent proximity tracking.** Separate journey lines per agent type — a fleet-level reliability map. *Bare cannot:* can't compare reasoning quality across its own agents on a common scale.

## M. Honest negatives / calibrated confidence (cross-cutting)

- **M1 ⭐ — Refuses to fabricate precision.** `is_kathekon: null`, `intake_clarifications` (principled withholding), `single_snapshot`, `indeterminate`, `lower_bound`, deferral-as-kathekon (AC-14). *Bare cannot:* a calibrated "I can't say" is itself a trust-bearing output an LLM rarely gives.
- **M2 — Stateless multi-turn quality guarantees.** `continuation_token` (resume-after-clarification) and `examination` markers (same-depth re-exam) survive a stateless API. *Bare cannot:* can skip a clarification or close a loop at a shallower depth.

## N. Purpose discovery (upstream; separate product)

- **N1 — Sage Calling.** Six-stage purpose-discovery for a *purposeless* agent (independence / unmet-need / proportion tests embed oikeiosis). *Bare cannot:* a task-less agent stalls or picks arbitrarily. *(Out of scope for a task-given benchmark — the benchmark hands the agent a task; noted for completeness.)*

## The through-line

The signature value over a bare agent is **not "ethical opinions"** (a bare model gives those freely and unreliably). It is that the practice turns reasoning into a **verifiable, longitudinal, tamper-evident, third-party-checkable record** — produced deterministically, welded to evidence (no credential without examination, no verdict without a narrative), scoped to whose interests were considered, prescriptive about the next step, honest about its own limits and confidence, and wrapped in a safety perimeter that survives integration and actively resists its own misuse. For the agent-developer audience this culminates in **the agent trust layer (C0): a persistent, verifiable profile/score attributed to the agent** — the central thing an external party uses to decide whether to trust or choose it. The most-overlooked benefits are the **structural guarantees** (A1–A4, B2–B3, C1/C3/C5, D7, G5, H2, I2–I3, J1–J4, K3–K4) — each closes a gaming or trust gap a bare model leaves open.
